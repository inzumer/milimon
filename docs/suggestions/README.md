## Orden sugerido

1. **Deploy oficial con dominio + auditoría de seguridad** (01): todo lo demás (Search Console,
   emails, redes) conviene hacerlo ya sobre el dominio definitivo.
2. **Tag Manager** (04): medir desde el lanzamiento para decidir con datos.
3. **CMS + primeras recetas y artículos** (02, 03): es lo que trae visitas y lo que se comparte.
4. **Tests e2e** (08) antes de sumar funciones grandes.
5. **Animaciones y monetización** (05, 06) cuando haya tráfico estable.
